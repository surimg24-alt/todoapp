# 습관 체크 웹 앱 기획서

## 1. 목적
- 운동, 물 마시기처럼 매일 반복하고 싶은 습관을 꾸준히 지키도록 돕는다.
- "오늘 했는지"를 빠르게 체크하고, 며칠째 이어가고 있는지 눈으로 바로 확인할 수 있게 한다.

## 2. 사용자
- 일상 습관(운동, 물 마시기 등)을 지키고 싶은 사람.
- 주로 휴대폰으로 짧게 들어와서 체크하고 나가는 사용자.

## 3. 기능 (3개)
1. **습관 추가/삭제**: 지키고 싶은 습관을 이름으로 등록하고, 더 안 할 습관은 목록에서 지운다.
2. **오늘 했는지 체크**: 습관마다 오늘 완료했는지 체크(토글)한다.
3. **연속 일수 표시**: 습관별로 며칠 연속으로 체크했는지 숫자로 보여준다.

## 4. 화면 구성
- **휴대폰 화면 1개로 구성** (화면 전환 거의 없이 한 화면에서 끝내는 것을 목표로 함).

```
[ 상단: 앱 이름 ]

[ + 습관 추가 입력창 / 추가 버튼 ]

[ 습관 목록 ]
  - 운동        🔥 5일 연속   [오늘 체크 ✅]  [삭제 🗑]
  - 물 마시기   🔥 2일 연속   [오늘 체크 ⬜]  [삭제 🗑]
  - ...
```

- 체크 버튼을 누르면 바로 ✅로 바뀌고, 연속 일수가 올라간다.
- 삭제 버튼을 누르면 확인 후 목록에서 사라진다.

## 5. 나중에 추가할 기능 (지금은 안 만듦)
- 습관별 알림(리마인더) 보내기.
- 달력으로 지난 기록 한눈에 보기.
- 습관 순서 바꾸기(드래그 정렬).
- 여러 기기(폰, PC)에서 같은 기록 보기 (데이터 동기화/로그인).
- 통계(이번 달 성공률 등) 보여주기.
