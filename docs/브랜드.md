# 습관 체크 브랜드 (조합: 아침 불꽃)

## 색 4가지
| 역할 | 색 값 | 쓰는 곳 |
|---|---|---|
| 주 색 | `#c8452b` | 주 버튼(한 화면에 하나), 체크한 날 칸, 선택된 탭 |
| 바탕색 | `#fefdfc` | 화면 바탕, 카드, 주 버튼 위 글자 |
| 글자색 | `#25221e` | 모든 글자, 아이콘 |
| 강조색 | `#f2a93b` | 연속 일수 표시처럼 작게 눈에 띄어야 하는 곳 (글자는 글자색) |

- 테두리, 구분선, 흐린 글자가 필요하면 새 색을 만들지 않고 글자색을 옅게(투명도) 해서 쓴다.

## 글꼴
- **프리텐다드(Pretendard)** 하나만 쓴다.
- 불러오기:
  ```html
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css">
  ```
- CSS: `font-family: "Pretendard", -apple-system, sans-serif;`
