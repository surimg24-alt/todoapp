# 디자인 레퍼런스 (스타일만 참고, 로고·그림·문구는 사용하지 않음)

- **기본 색**: 따뜻한 미색 바탕 `#fefdfc`, 아주 연한 크림 띠 `#fff6f0`, 글자는 완전한 검정이 아닌 잉크색 `#25221e`, 보조 글자 `#6f6c69`, 테두리·구분선 `#d7d6d4`.
- **강조 색**: 빨강-주황 `#e34432`는 한 화면에 버튼 하나에만 쓰고, 진한 빨강 `#cf3520`은 작은 라벨, 파랑 `#0f66ae`는 링크, 연초록 `#f0f6df` 바탕 + 초록 `#446c3d` 글자는 완료 표시에 쓴다.
- **글꼴**: 제목은 Graphik(없으면 Inter)으로 굵고 자간을 살짝 좁히고, 버튼·입력창·본문은 Inter 12~18px로 자간을 살짝 넓힌다. 본문 크기는 16px, 줄 간격은 1.5.
- **간격**: 4px 단위(4·8·12·16·24·32·48)로 맞추고, 카드 안쪽 여백은 16~24px, 요소 사이는 16px, 큰 구역 사이는 48~80px로 넉넉하게 둔다.
- **버튼·카드 모양**: 버튼·입력창·카드 모두 모서리 8px로 둥글게 한다. 주 버튼은 `#e34432` 바탕에 미색 글자(Inter 600, 16px, 안쪽 여백 12px 24px)이고, 보조 버튼은 배경 없는 글자 링크다. 그림자는 1px짜리 아주 옅은 선 정도만 쓴다.
